# Tailwind Mastery ⚡

This project was developed as part of my learning journey with **Rocketseat**, focusing on mastering **Tailwind CSS** using **Vite** as a modern and high-performance front-end build tool.

The main goal is to deepen my understanding of utility-first CSS, responsive design, and best practices for building scalable and maintainable user interfaces.

---

## 🧪 Technologies Used

- **Vite** – Fast build tool and development server
- **Tailwind CSS** – Utility-first CSS framework
- **PostCSS**
- **Autoprefixer**
- **HTML5**
- **JavaScript / TypeScript** (depending on project setup)

---

## 🎯 Project Goals

- Master Tailwind CSS fundamentals and advanced concepts
- Build responsive layouts using utility classes
- Apply best practices taught in the Rocketseat course
- Create reusable and consistent UI components
- Improve front-end workflow with Vite
